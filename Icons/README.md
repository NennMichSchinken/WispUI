# Icons

WispUI's line icons are **Lucide** (<https://lucide.dev>), ISC licence, copyright Lucide
Icons and Contributors. `LUCIDE-LICENSE.txt` is their licence text and must stay with any
copy of this plugin.

There are no files to ship here. Lucide publishes no font, so the outlines are stated in
`Style/LineIcons.cs` as the `d` strings out of the icon's own `.svg`, copied unchanged, with
the file name beside each one. Adding an icon means copying one more string out of the set —
nothing is generated and nothing is traced by hand.

The set was chosen because LumenUI uses it: the two projects then look like one hand, and the
icons belong to us rather than to whichever icon font a framework happens to bundle.
